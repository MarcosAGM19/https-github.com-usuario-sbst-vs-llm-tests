# SBST vs LLM Comparison Project

This project is designed to compare Software-Based Testing (SBST) techniques with Large Language Models (LLMs).

## Directory Structure
- **/evosuite**: Contains files related to EvoSuite, a tool for automatic test generation.
- **/llm**: Contains files relevant to the integration and usage of Large Language Models.
- **/src**: The source code for the project.
- **/docs**: Documentation for the project.
